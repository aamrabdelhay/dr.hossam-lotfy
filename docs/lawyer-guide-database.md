## 5) Database Schema مقترح (Prisma) — يندمج مع الحالي

```prisma
model LegalDirectoryCategory {
  id          String   @id @default(cuid())
  slug        String   @unique
  nameAr      String
  nameEn      String?
  sortOrder   Int      @default(100)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  items       LegalDirectoryItem[]
  @@map("legal_directory_categories")
}

model LegalDirectoryBuilding {
  id          String   @id @default(cuid())
  slug        String   @unique
  nameAr      String
  nameEn      String?
  address     String?
  governorate String?
  city        String?
  lat         Float?
  lng         Float?
  mapsUrl     String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  items       LegalDirectoryItem[]
  @@map("legal_directory_buildings")
}

model LegalDirectoryItem {
  id                        String   @id @default(cuid())
  slug                      String   @unique
  officialNameAr            String
  officialNameEn            String?
  categoryId                String
  subType                   String? // ابتدائية / جزئية / مأمورية ضرائب ...
  governorate               String?
  city                      String?
  district                  String?
  fullAddress               String?
  phone                     String?
  email                     String?
  website                   String?
  googleMapsUrl             String?
  lat                       Float?
  lng                       Float?
  workingHours              String?
  services                  String[] @default([])
  jurisdiction              String?
  relatedEntityIds          String[] @default([])
  requiresPersonalAttendance Boolean @default(true)
  hasOnlineService          Boolean  @default(false)
  onlineServiceUrl          String?
  source                    String?
  lastVerified              DateTime?
  confidence                String   @default("needs_verification") // high, medium, needs_verification
  distanceFromDokkiKm       Float?
  distanceBucket            String? // 0-5, 5-10, 10-20...
  buildingId                String?
  building                  LegalDirectoryBuilding? @relation(fields: [buildingId], references: [id], onDelete: SetNull)
  category                  LegalDirectoryCategory @relation(fields: [categoryId], references: [id], onDelete: Cascade)
  searchKeywords            String[] @default([]) // "توكيل، سجل تجاري، نقل ملكية"
  createdAt                 DateTime @default(now())
  updatedAt                 DateTime @updatedAt

  @@index([governorate, city])
  @@index([categoryId, subType])
  @@index([distanceFromDokkiKm])
  @@index([buildingId])
  @@map("legal_directory_items")
}
```

- يضاف `@@fulltext` أو يستخدم `/api/search` الحالي ليشمل الجدول الجديد.
- يضاف enum `ConfidenceLevel` لو رغبت.

## 6) حساب المسافة من الدقي

- نقطة مرجعية: 30.0380,31.2000 (الدقي)
- استخدم Haversine للمسافة الخطية + تخزين `distanceBucket`
- لاحقا يمكن تحسين بـ Google Distance Matrix للطرق.

```ts
function haversine(lat1, lon1, lat2, lon2) {
  const R=6371;
  const dLat=(lat2-lat1)*Math.PI/180;
  const dLon=(lon2-lon1)*Math.PI/180;
  const a=Math.sin(dLat/2)**2 + Math.cos(lat1*Math.PI/180)*Math.cos(lat2*Math.PI/180)*Math.sin(dLon/2)**2;
  return R*2*Math.atan2(Math.sqrt(a),Math.sqrt(1-a));
}
```
